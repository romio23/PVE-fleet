Een API-token maken in Proxmox

Eén keer per cluster en één keer per losse node, in de shell van een node:

pveum user add dashboard@pve --comment "PVE Fleet"
pveum role add FleetOperator --privs "VM.PowerMgmt VM.Snapshot VM.Snapshot.Rollback VM.Backup VM.Migrate Datastore.AllocateSpace Sys.PowerMgmt VM.Console Sys.Console VM.GuestAgent.Audit"
pveum acl modify / --users dashboard@pve --roles PVEAuditor,FleetOperator
pveum user token add dashboard@pve fleet --privsep 0

# Token al gemaakt in de webinterface (Privilege Separation aan)? Dan ook:
pveum acl modify / --tokens 'dashboard@pve!fleet' --roles PVEAuditor,FleetOperator

Het commando pveum user token add toont het geheim (value) één keer. Vul hier in: token-ID dashboard@pve!fleet en dat geheim. Alleen kijken, zonder acties? Laat dan de regel met FleetOperator weg en gebruik --roles PVEAuditor.

Via de webinterface kan het ook: Datacenter › Permissions › Users, API Tokens (vink Privilege Separation uit) en Add › User Permission. Twijfel je of alles goed staat? Klik bij je server op Bewerken › Verbinding testen: daar zie je per onderdeel of het token de juiste rechten heeft.
